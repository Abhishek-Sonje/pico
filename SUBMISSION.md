# Pico Submission Runbook

## Two-minute demo

- **0:00–0:15** — Startup research is fragmented; Pico turns the public YC directory into decision-ready evidence.
- **0:15–0:35** — Show the YC Companies Scraper Studio collector and its structured output contract.
- **0:35–0:55** — Show the controlled staging failure, Pico preserving the last-known-good dataset, CLI heal, approval, and successful rerun.
- **0:55–1:35** — Use the Opportunity Radar, filter the live dataset, open a company, and compare two companies.
- **1:35–1:50** — Show the Scraper Flight Recorder and recent run history.
- **1:50–2:00** — Close on Next.js, Neon, Bright Data, deterministic scoring, and the live deployment.

## Submission checklist

- Public repository with visible commit history
- Live Vercel URL and `/api/health` returning `ready`
- Sanitized scraper recovery evidence from `RECOVERY.md`
- Hero, comparison, and flight-recorder screenshots
- Demo video link
- Project description and explicit Scraper Studio workflow
- No API keys, operator keys, collector IDs, or `.env` contents in screenshots

## One-line pitch

Pico is a self-healing YC opportunity radar that turns a public company directory into validated, explainable career decisions.
